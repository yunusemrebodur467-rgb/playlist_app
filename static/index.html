🔌 Chrome eklentisiyle bağlan (önerilen — secret/çerez kopyalama yok)
  1. Chrome adres çubuğuna chrome://extensions yaz, Enter'a bas.
  2. Sağ üstte Geliştirici modu'nu aç.
  3. Paketlenmemiş öğe yükle → eklenti klasörünü seç.
  4. open.spotify.com ve music.youtube.com'da giriş yapılı olduğundan emin ol.
  5. Eklenti yerel uygulamayla buluşunca oturumları otomatik iletir (çerez kopyalama yok). Gerekirse araç çubuğundaki PopGün Köprüsü simgesine tıkla — iki butona bas.

🎬 YouTube Music — Bağlan

Eklenti otomatik okur — çerez kopyalama gerekmez.

1. Chrome araç çubuğundaki PopGün Köprüsü simgesine tıkla (açık değilse chrome://extensions'dan eklentiyi etkinleştir).
2. Açılan açılır menüde YouTube Music'i bağla'ya bas. Eklenti, açık YT Music oturumunun çerezlerini otomatik alır.
3. Buraya dönüp 🔄 Yenile'ye bas.

Eklenti yoksa çerez elle kopyalanabilir (yalnızca ikincil yol):

1. music.youtube.com'da oturum aç.
2. F12 (DevTools) → Application / Uygulama → Cookies → https://music.youtube.com.
3. Aşağıdaki kutuya ad=deger; ad2=deger2; ... biçiminde yapıştır (şu adlar: __Secure-3PAPISID, __Secure-3PSID, SID).

🟢 Spotify — Bağlan

Eklenti otomatik okur — çerez kopyalama gerekmez.

1. Chrome araç çubuğundaki PopGün Köprüsü simgesine tıkla (açık değilse chrome://extensions'dan eklentiyi etkinleştir).
2. Açılan açılır menüde Spotify'ı bağla'ya bas. Eklenti, açık Spotify oturumunun sp_dc çerezini otomatik alıp yerel uygulamaya iletir.
3. Buraya dönüp 🔄 Yenile'ye bas.

Eklenti yoksa çerez elle kopyalanabilir (yalnızca ikincil yol):

1. open.spotify.com'da oturum aç.
2. F12 (DevTools) → Application / Uygulama → Cookies → https://open.spotify.com.
3. sp_dc çerezinin Value sütununu kopyala (adını veya = işaretini değil).
